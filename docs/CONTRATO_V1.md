# Market Explorer — primeiro percurso determinístico

O motor recebe sinais abertos, **sem array de mercados predefinidos**.
Uma hipótese só passa a `test` quando existem fontes com URL, data, evidência
e permissão de uso; não é confundida com rentabilidade ou viabilidade confirmada.

A saída é compatível com `POST /v1/hypotheses` da Platform.
Apenas a Platform persiste dossier e o Website apresenta.

A pesquisa autónoma de novas fontes, amostragem remota e avaliação económica
profunda **ainda dependem de conectores reais e posterior integração de IA**.
Este código não afirma ter pesquisado automaticamente dados de mercado.
Não são criados jobs CircleCI nesta fase.
